# Data Cleaning & Transformation

**Type:** Portfolio project using demo spreadsheet and CSV data  
**Tools:** Microsoft Excel, Power Query

## Objective
Prepare messy spreadsheet and CSV data for reliable analysis.

## What I worked on
- Duplicate removal
- Data type corrections
- Text standardization
- Date and number formatting
- Missing-value checks
- Field validation
- Category cleanup

## What I did
- Inspected columns for missing, duplicated, and inconsistent values.
- Standardized text, dates, number formats, and category labels.
- Removed or flagged invalid rows according to clear rules.
- Prepared an analysis-ready output using Excel and Power Query concepts.
- Documented the transformation logic so the workflow can be repeated.

## Business value
Clean and consistent data reduces reporting errors and makes downstream analysis faster and more reliable.

## Status
Portfolio / practice project. Demo data only.
