FÓRMULAS

Relaciones fundamentales

pHpH = −log₁₀[H⁺]
pOHpOH = −log₁₀[OH⁻]
RelaciónpH + pOH ≈ 14 a 25 °C
Concentración H⁺[H⁺] = 10−pH
Concentración OH⁻[OH⁻] = 10−pOH

La escala 0–14 es la representación educativa habitual para soluciones acuosas. En química real pueden existir valores fuera de ese intervalo.
