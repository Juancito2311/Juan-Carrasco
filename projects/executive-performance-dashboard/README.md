# Executive Performance Dashboard

**Type:** Portfolio project using demo business data  
**Tools:** Power BI, Power Query, data modeling, KPI cards, charts, slicers, basic business measures

## Objective
Build an executive dashboard that communicates business performance through a clean visual hierarchy.

## What I analyzed
- Revenue
- Profit
- Target attainment
- Regional performance
- Business trends

## What I did
- Imported and transformed demo source tables with Power Query.
- Organized fields into a simple data model.
- Created KPI cards, charts, slicers, and comparisons against targets.
- Structured the report around the questions a manager is likely to ask first.

## Business value
The dashboard gives decision-makers a fast overview of performance and highlights areas that may require attention.

## Status
Portfolio / practice project. Demo data only.
