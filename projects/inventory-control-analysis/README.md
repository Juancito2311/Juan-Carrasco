# Inventory Control & Reorder Analysis

**Type:** Portfolio project using demo inventory data  
**Tools:** Microsoft Excel, lookup formulas, logical formulas, conditional formatting, KPI cards, charts

## Objective
Build an inventory tracking model that highlights low-stock items and compares current stock with reorder points.

## What I analyzed
- Current stock levels
- Reorder points
- Low-stock items
- Inventory status by category
- Reorder priorities

## What I did
- Created a structured SKU table with stock, reorder point, category, and status fields.
- Used lookup and logical formulas to flag items requiring attention.
- Applied conditional formatting to make critical stock situations visible immediately.
- Summarized inventory health with KPIs and charts.

## Business value
The report supports purchasing and warehouse decisions by reducing manual checking and making reorder priorities visible quickly.

## Status
Portfolio / practice project. Demo data only.
